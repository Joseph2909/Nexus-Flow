# NexusFlow

A lightweight visual workflow builder built with React, Vite, React Router, and React Flow.

## Run locally

```sh
npm install
npm run dev
```

## Using the app

- Visit `/` for the workspace overview and `/canvas` to edit a flow.
- Drag a Trigger, Action, or Output from the node library onto the canvas, or click a node to add it in the center.
- Move nodes by dragging them. Create a connection by dragging from one node's handle to another node's handle.
- Use the canvas controls to zoom and pan, and Reset to restore the starter flow.

Run `npm run build` to create a production build.
